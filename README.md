# Civic Access Alliance WCAG Audit Kit

WCAG audit kit for Civic Access Alliance ecommerce UI reviews.

Production: https://civic-access-wcag-audit.vercel.app

## Scope

- WCAG POUR principles
- Semantic HTML and skip links
- Visible focus states
- Accessible form labels and helper text
- Contrast-conscious interface design

## Stack

- HTML and CSS
- Vercel hosting

## Local Operations

```bash
npm run start
```

The audit kit is served as a static accessibility review interface and can be deployed directly through Vercel.
