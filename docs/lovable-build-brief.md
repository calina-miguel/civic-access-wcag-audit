# Civic Access Alliance WCAG Audit Kit

Build an accessibility audit interface for Civic Access Alliance, an organization reviewing ecommerce UI components against WCAG principles. The front-end should make accessibility status, audit notes, and checkout field patterns easy to review.

Use a responsive React front-end suitable for Vercel deployment. The first screen should show the Civic Access Alliance audit kit title, WCAG principle score cards, and a clear path to the checkout field pattern.

Required features:

- Skip link and semantic page structure.
- WCAG POUR score grid: Perceivable, Operable, Understandable, Robust.
- Accessible checkout field pattern with label, helper text, required state, and error messaging behavior.
- Audit checklist for contrast, alt text, captions, keyboard support, focus visibility, form labels, readable errors, and semantic structure.
- Status states for Pass, Review, and Needs Work.
- Notes area for remediation guidance.
- Responsive layout for mobile and desktop.
- Strong visible focus states and keyboard-operable controls.

Visual direction:

- Clean civic and accessibility review interface.
- High contrast text, restrained off-white background, clear blue/teal action color, amber focus color, and minimal decoration.
- Prioritize readability and accessible spacing.
- Cards only for audit modules and form pattern areas, with modest radius and clean spacing.
